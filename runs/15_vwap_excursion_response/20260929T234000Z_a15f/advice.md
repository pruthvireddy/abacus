Preserve negative and inconclusive cells. A higher-threshold return rate is not a paired improvement over an earlier 2-sigma entry. Long MFE equals short MAE on the same path, so excursion asymmetry alone is not a profit measure. A barrier race is only the specified 0.5-sigma first move.

No strategy is promoted or existing strategy card overwritten. A future trading study would need separately prespecified execution, costs, controls and genuinely new evaluation history. True volume delta requires a separate pinned source.
