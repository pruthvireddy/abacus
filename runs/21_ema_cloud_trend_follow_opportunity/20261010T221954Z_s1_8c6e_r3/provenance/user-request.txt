5. SIGNAL TIMING AND STATE

On 5m signal candles:
Use that completed candle’s current close-derived EMA cloud.

On 3m signal candles:
Use the latest valid scheduled 5m cloud completed at the 3m candle’s OPEN. Freeze that level for the whole touch test.

Example:
09:33–09:36 uses the cloud completed at 09:30, not the cloud completing at 09:35.

Require:
- The mapped source is the latest expected completed scheduled slot.
- Valid source/warmup.
- Matching source and signal contracts.

A missing/partial latest source slot makes mapped features undefined immediately. Never carry an older ready cloud across a missing slot or roll. Retain invalid/reset records during mapping.

Signal rules:
- Bullish: EMA20 > EMA50.
- Bearish: EMA20 < EMA50.
- Equality: no directional event.
- Full candle strictly above the bullish cloud arms Buy.
- Full candle strictly below the bearish cloud arms Sell.
- Inclusive slow touch: low <= EMA50 <= high.
- Accept only with valid data, matching direction, pre-bar armed state and fixed width gateway.
- Any penetration of the selected slow EMA consumes the setup, including rejected touches and gaps through the level.
- A fast-only touch does not consume the slow setup.
- Rearm only after a new full departure outside the entire cloud.
- Clear armed state on invalid features, direction change or reset.

Preserve the source’s inclusive threshold tolerance. Do not round EMAs or widths to ticks.

Save raw technical candidates, pre/post state, suppressions and accepted events BEFORE future-path exclusions.

6. FORWARD OUTCOMES

Exclude the signal candle.

For the following H scheduled chart slots:
E = unadjusted signal close
U = highest future high
L = lowest future low
C_H = terminal close
d = +1 Buy, -1 Sell

Buy:
MFE = max(0, U-E)
MAE = max(0, E-L)

Sell:
MFE = max(0, E-L)
MAE = max(0, U-E)

Signed terminal delta = d × (C_H-E).

Compute favorable/neutral/adverse close shares and MFE>MAE share with declared tie handling.

Allow overlapping observations. Opposite signals do not terminate them.

Do not compress unknown missing chart slots. Record nominal active minutes and actual elapsed time. Censor horizons crossing contract switches, missing/partial required bars, the development endpoint or other declared invalid boundaries.

Keep shorter completed horizons where valid.
Undefined outcomes remain null, never zero.
Future-path exclusions must not change signal acceptance or later pullback state.
Keep state continuous across years and split boundaries.

Report raw points separately by product and ATR-normalized outcomes where valid. MAE/MFE are price-path observations, not executable profits or optimized stops/targets.
