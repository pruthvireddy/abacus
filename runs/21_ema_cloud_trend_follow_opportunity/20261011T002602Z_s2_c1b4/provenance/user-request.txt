5. IMPLEMENT INDEPENDENT FAST AND SLOW STREAMS

Fast selects EMA20.
Slow selects EMA50.

Each stream owns its own armed/consumed state.

For each stream:
- Full strict departure outside the entire bullish cloud arms Buy.
- Full strict departure outside the entire bearish cloud arms Sell.
- Inclusive range touch is low <= selected EMA <= high.
- Acceptance uses pre-bar state, direction, data eligibility and fixed width.
- Any selected-EMA penetration consumes that stream’s setup, including width rejection or a gap through the level.
- A new full-cloud departure rearms it.
- Invalid data/features, equality, direction changes and contract resets clear state.

A fast touch or rejection must not consume the slow setup.
A slow-stream decision must not change fast state.
Do not derive either stream by filtering the other’s accepted events.

Preserve timing:
- 5m candles use their current completed close-derived cloud.
- 3m candles use the latest valid scheduled 5m cloud completed at their OPEN.
- Missing/partial latest source slots invalidate features immediately.
- Source and signal contracts must match.
- Never carry stale features across an invalid slot or roll.

Future path completion, opposite events, pairing labels and report filters must never alter acceptance.

Reuse Stage 1’s forward-outcome formulas and scheduled-slot timeline.
