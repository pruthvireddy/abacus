## C pre-touch context (information fixed before touch-bar open)

Link each C event's saved `departure_feature_index` to the same product/session/timeframe/anchor feature sequence. Use only completed feature bars from that departure through the bar immediately before the touch bar opens. Fail on a missing linkage, changed contract, inactive anchor, or nonconsecutive episode. The touch-bar extremes are not pre-touch predictors.

- Departure strength: absolute departure close distance from contemporaneous VWAP divided by departure sigma. Bins `[1,1.5)`, `[1.5,2)`, `2+`.
- Peak pre-touch excursion: maximum same-side *completed close* distance from each bar's contemporaneous VWAP, normalized by that bar's available sigma. Bins `[1,1.5)`, `[1.5,2)`, `2+`. Separately record the maximum outward completed-bar high/low relative to the **frozen departure VWAP**, divided by departure sigma; this is descriptive and cannot substitute for the close-based bin.
- Departure-to-touch time: from departure availability to touch-bar open, bins `<=15`, `16–45`, `>45` elapsed minutes. Peak-to-touch time uses the peak close's availability. Count completed closes on the departure side at or beyond 1σ before touch.
- Approach speed: peak close-distance minus last pre-touch close-distance, divided by elapsed minutes from the peak close to touch open, in sigma per minute; `no_elapsed_peak` is separate. Report as a continuous distribution, and compare the predeclared `<=15` versus `>15` minute peak-to-touch cut among peak `2+` events. This interaction is a primary C context question; all other cross-cuts are exploratory.
- Touch-bar close class (`approach_side`, `zone`, `opposite_side`) is known only at touch-bar close and is a separate signal-time feature. The earlier simple confirmation subset showed no lift; report this interaction without substituting it for the all-touch population.

## A pre-exit context (known at exit-bar close)

- Exit strength: absolute signal close distance in sigma; bins `(2,2.25)`, `[2.25,2.75)`, `2.75+`. Report the actual excess beyond 2σ in ticks as well. At exact 2.25/2.75 values use the higher bin. The published exit must be strictly beyond 2σ.
- Signal-bar outward close location: `(close-low)/(high-low)` for upper exits, `(high-close)/(high-low)` for lower exits, with zero-range separate. `>=0.75` is an outward close; lesser values are separate. All values use the completed signal bar.
- Prior 30-minute price trend: side-signed adjusted close change from the completed feature bar at or before signal availability minus 30 minutes to the signal close, divided by signal sigma. The reference bar must be in the same active anchor/session; unavailable is separate. `>=1σ`, `(0,1σ)`, and `<=0` are the fixed trend bins. Record same-interval side-signed VWAP slope divided by sigma and sigma expansion ratio; do not use future VWAP motion.
- Last near-VWAP completed close: elapsed minutes since the latest same-window, same-anchor completed close within 0.25 contemporaneous sigma of VWAP, or `none_in_window`. This is exploratory.
- The primary A context interaction is exit strength × prior-trend bin, stratified by product. Compare fade and outward 3σ-before-frozen-return evidence; rows already beyond frozen 3σ at the reference are a separate population, and intraminute order bounds remain intact.

## Common regime and session features

Compute daily true range from the pinned **adjusted** 2m feature-bar daily high/low and preceding adjusted session close, using only complete eligible published days. A signal-day ATR14 is the mean of the 14 most recent *prior* complete product-sessions; missing history is a separate class. Assign low/middle/high ATR bins by product-specific terciles learned only from development days, then hold boundaries fixed. Do not use the current day's completed range.

For each observation window, the 30-minute opening balance consists of the first 30 unadjusted one-minute bars after the pinned local window start. Its high/low/width are known at or after that interval's exclusive end. Earlier events have `opening_balance_unavailable`. At the event signal close, classify `above`, `inside`, or `below` the known balance (inclusive boundaries are inside), and report balance width divided by prior ATR14. Define product/window-specific width terciles from development; do not pool tick values across products. This is a context cut, not a new entry filter. Retain source-day/contract reconciliation and the pinned completeness limitation.

Local-versus-Globex geometry at the signal: price above both known VWAPs, below both, or between; local/Globex separation divided by local sigma; unavailable for Globex/full-session or inactive local anchor. Use only feature values available at signal close. Analyse local-window events with the local anchor separately from Globex-anchor events in that window. Other descriptive dimensions: product, timeframe, upper/lower or long/short direction, chronological split, year, anchor/window, anchor age `[30,60)`, `[60,120)`, `120+`, and C first versus later ordinal. Timeframe/anchor views are overlapping observations, not independent signals.
