# First countertrend Range XV bar: subsequent bar counts

Frozen before outcome extraction on 2026-09-24 (see `study.yaml`). The seven enhanced files in the 2019-11-01–2026-09-24 snapshot are the only event inputs. Older exports and sealed results are context, never pooled.

## Observation and eligibility

One observation is C1, the first non-doji bar opposite a preceding uninterrupted run of non-doji bars in one inferred 18:00 New York session. A doji ends a run and cannot be C1; no run crosses a session boundary. Direction is sign(close−open) in integer ticks. Prior length 1–2 is context; 3–4, 5–7, 8+ are main trend groups. C2/C3/C4 are successive physical bars, including dojis. A doji fails same-direction continuation and is counted separately. Signal time is C1's `bar_completion_timestamp_proxy`, the next bar's start in the same session. C1 with unavailable or equal-second completion is excluded from primary estimates. Primary outcomes require C2 and C3 to be strictly completed within that session. C4 and a strict C4 completion are required only for the three-subsequent-bar outcome. No bars or outcomes cross a session or export boundary. Both directions remain separate in primary tables.

Primary probability is `C2 and C3 directions == C1 direction`; C1 is excluded from the two-more count. Secondary probabilities: C2 follows; C3 follows conditional on C2 following; C2–C4 all follow; C2 immediately resumes the old trend. The exact subsequent same-direction run ends at the first doji/opposite bar and is right censored when a session/export ends; full exact counts and censor flags are retained. P(C2), P(C2&C3), and resumption share the primary eligible denominator. Conditional P(C3|C2) uses primary-eligible C2 successes. P(three more) has its own C4-eligible denominator.

## Frozen groups

Assign session from C1's completion proxy in normalized New York wall time, using half-open windows: Asia 18:00–03:00 (wraps midnight); London/pre-NY 03:00–09:30; NY morning 09:30–12:00; NY afternoon 12:00–16:00; transition 16:00–18:00. DST is already reflected in the enhanced wall clock. Half-hours are exploratory only. The source timezone is inferred, not checked against ATAS settings, so labels are conditional on that interpretation.

C1 structure: body fraction `|close−open|/(high−low)` ≥0.70; directional close location ≥0.80; opening-side adverse wick fraction <0.20; directional close strictly beyond the preceding bar's directional extreme. All use C1 and earlier bars only. Prior-trend structure: average opposing wick fraction <0.20; net signed move from first run open to last run close ≥0.75×RXV setting×run length; median prior-bar formation time <60 seconds. Each comparison stays within chart, direction, prior-length bin, and session. Run-extreme break is not tested as an independent feature because of its one-bar mechanical relationship.

Larger pairs: ES 4→5, ES 5→6, GC 6→10, NQ 10→20. Attach only the latest larger bar whose next-bar-start completion proxy is strictly earlier than C1's proxy, within the same inferred session. Equal-second joins are excluded and counted; include them only in a sensitivity using the last strictly earlier state. Classify C1 as against the larger direction (first attempt) or aligned (snapback); show the one-bar aligned snapback separately from extended-trend attempts. Same product settings are transformations of shared trades and are never pooled as independent evidence. ES 6, GC 10, and NQ 20 have no larger pair in this snapshot.
