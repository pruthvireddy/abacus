# Trader Assistant manual source-review protocol

Protocol 1.0.0 · October 13, 2026 · qualitative external source review.

## Authorized scope

Review the public manual at
[willyalgotrader.pro](https://willyalgotrader.pro/strategy/manual/), navigating
all twelve chapters and the update. Create a simple, lightweight Abacus reading
companion with a chapter contents list, original concise explanations, links to
the full source and original static illustrations.

The user selected this companion after confirming that reproduction rights are
unavailable or uncertain. Exclude a full-text mirror, copied source charts,
screenshots reproducing the source and extensive paraphrase that substitutes
for the book. Keep the author's complete material at its original links.

No market-data analysis, strategy implementation, performance calculation,
parameter selection or hosted deployment is authorized by this protocol.

## Source observations

Record the source URL and the user's local review date, October 13, 2026.
Inspect each chapter and the update; distinguish source descriptions and claims
from Abacus's interpretation. Preserve concise selected reading observations,
chapter locators and the original companion as authored review artifacts.
Do not infer authorship, publication dates or instrument coverage that the source
does not establish.

The live external source is not a frozen input. The review retains neither a
complete source snapshot nor the original image bytes, and does not declare
source-byte hashes. A locator and access date establish what was consulted,
not byte-level reproducibility or authentication of the source's claims.
Hash the actual authored observations, companion and original illustrations
separately when preparing the run.

## Content and interpretation

Use brief original explanations to orient a reader before following the
corresponding chapter link. Keep unresolved definitions or discretionary
judgments explicit. Do not infer an executable trading policy from narrative
examples. Any numbers mentioned from the source remain attributed claims,
never an Abacus estimate or an empirical sample.

Create explanatory PNG schematics from authored geometry. Label them as original
illustrations rather than source charts or market data. Use accessible
alternative text and captions, retain their source/generator identities and
hash the exact raster bytes selected for publication. Do not add embedded video,
remote image loading, analytics or an application backend.

`work/24_trader_assistant_manual/20261014T023500Z_manual24_8c1d7f/`.
Prepare the offline HTML/Markdown companion, qualitative source observations,

Seal at
`runs/24_trader_assistant_manual/20261014T023500Z_manual24_8c1d7f/` only after
the declared checks pass. Completed evidence is immutable. Do not append a
correction to this run; create a new source-review run for changed interpretation

Use the existing Narada 1.1 plain-text, raster-figure and external-reference
contract. Publish only the selected companion and owned assets through the
publisher under the immutable ID
`trader-assistant-manual-20261013-companion-v1`. Author catalog selections
explicitly; preserve all existing reports and routes.

## Checks and limits

Check chapter/update coverage, source links, concise original wording, schematic
labels, selected asset hashes and absence of copied source text/images. Preserve
the distinction between unavailable source-byte verification and verified local
authored artifacts. No numerical test suite is applicable to this source review.

Validate workspace documentation, navigation metadata and index freshness after
the sealed run exists. Run Narada verify/test/lint/build, static-preview HTTP
smoke and actual desktop/mobile browser inspection. Private source auditing may
check the explicitly mapped sealed publication files and their hashes; it does
not verify the live manual or revalidate trading claims.

No positive performance finding follows from this work. A future empirical
study needs its own authorization, causal definitions, pinned datasets,
execution assumptions, comparisons and validation protocol.
