# Private source-audit compatibility adapter

Narada's generic private audit accepts `result: passed`; the immutable sealed producer receipt uses `status: passed`. This additive private revision supplies that vocabulary adapter after freshly verifying actual saved source cells, original receipt pins, and exact copied publication/map/asset bytes. Original receipts and run manifest are retained under `provenance/`.

The existing immutable publication ID and all public report/asset bytes remain unchanged. This is a private provenance mapping target, not a new publication or a scientific rerun. No sealed run, generated public bundle or hosted state was modified.
